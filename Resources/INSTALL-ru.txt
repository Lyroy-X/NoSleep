NoSleep — установка

Эта сборка: macOS 14 Sonoma и новее, Apple Silicon и Intel. Проверена на macOS 27.0.1 / Apple Silicon; запуск на Intel и более ранних macOS отдельно не проверялся.

1. Перетащите NoSleep.app на значок Applications («Программы»).
2. Откройте «Настроить защиту сна.command». Прочитайте пояснение, введите «да» и пароль администратора. Пароль вводится в Терминале, символы не отображаются. Настройка разрешает только вашей учётной записи две команды управления сном, а не все команды администратора.
3. Откройте NoSleep из папки «Программы» и включите нужные галочки.
4. Извлеките диск NoSleep.

Если macOS блокирует запуск: сначала попробуйте открыть файл, затем откройте «Системные настройки → Конфиденциальность и безопасность» и найдите «Открыть всё равно» именно для этого файла. Проверьте, что файл получен от отправителя, которому доверяете. У приложения локальная подпись, но нет Developer ID и нотариального заверения Apple.
Справка Apple: https://support.apple.com/102445

Переключатели независимы:
• «Не позволять Mac засыпать» — запрет сна, включая закрытую крышку.
• «Не гасить экран при бездействии» — экран остаётся включённым при бездействии. Закрытие крышки физически выключает встроенный экран.
• «Выключить всё» снимает обе защиты.
• «Выйти» снимает защиту и завершает приложение. Закрытие только окна оставляет приложение в фоне.

Для запрета сна нужна учётная запись с правом установки через sudo. На корпоративном Mac администратор может запретить такую настройку. Без интернета приложение работает локально, но облачные программы всё равно требуют связи.

Если возникнет ошибка, её текст отображается в окне. Журнал: ~/Library/Application Support/NoSleep/events.log.

Удаление: нажмите «Выйти», затем удалите NoSleep.app. Дополнительное правило питания называется /private/etc/sudoers.d/nosleep_UID, где UID — числовой идентификатор пользователя; администратор может удалить именно этот файл, если правило больше не нужно.
