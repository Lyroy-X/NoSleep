NoSleep — три простых шага

1. Перетащи NoSleep.app на значок Applications («Программы»).
2. Открой NoSleep из «Программ» и нажми «Настроить NoSleep».
3. Подтверди настройку паролем администратора Mac. Это нужно только один раз.

Готово: запрет сна включится автоматически. Если настройка уже выполнена, приложение не просит пароль снова. Галочка «Не гасить экран» включается отдельно по желанию. Терминал и ручные команды не нужны.

Если macOS блокирует первое открытие: после попытки запуска открой «Системные настройки → Конфиденциальность и безопасность» и нажми «Открыть всё равно» для NoSleep. У этой сборки нет Developer ID и нотариального заверения Apple. Проверяй, что получил файл от доверенного отправителя.
Справка Apple: https://support.apple.com/102445

Apple Silicon и Intel, macOS 14+. Проверено на macOS 27.0.1 / Apple Silicon; запуск на Intel отдельно не проверялся.

«Выключить всё» снимает обе защиты. «Выйти» снимает защиту и завершает приложение. Закрытие только окна оставляет приложение в фоне.

Для настройки нужен пароль администратора. NoSleep разрешает только текущей учётной записи две операции управления сном без повторного пароля, не остальные команды администратора. На корпоративном Mac настройку может ограничить его администратор.

Защита экрана относится к гашению при бездействии. Закрытие крышки физически выключает встроенный экран. Без интернета NoSleep работает локально, но облачным приложениям нужна связь.

При ошибке причина отображается в окне. Журнал: ~/Library/Application Support/NoSleep/events.log.
