# NoSleep

Приложение для macOS с двумя независимыми переключателями: **не позволять Mac засыпать** и **не гасить экран при бездействии**. Работает в фоне; окно открывается из Dock или значка луны в меню macOS. Поддерживает светлую и тёмную темы.

## Установка

1. Откройте [последний релиз](https://github.com/Lyroy-X/NoSleep/releases/latest) и скачайте **NoSleep-universal.dmg** из раздела Assets. Пока репозиторий приватный, нужен доступ к нему.
2. Откройте DMG и перетащите **NoSleep** на значок **«Программы»**. Извлеките образ и запустите NoSleep из папки «Программы».
3. Если macOS сообщает, что разработчика нельзя проверить или приложение не нотарифицировано, откройте **Системные настройки → Конфиденциальность и безопасность → Открыть всё равно**, затем подтвердите запуск. Делайте это только для файла из релиза этого репозитория. Текущая сборка использует ad-hoc подпись и не имеет Developer ID / нотарификации Apple. [Инструкция Apple](https://support.apple.com/102445).
4. Нажмите **«Настроить NoSleep»**. macOS запросит пароль администратора для первоначальной настройки запрета сна. После успешной настройки защита сна включится автоматически. Защита экрана включается отдельным переключателем.

Нужны **macOS 14+** и права администратора для первоначальной настройки сна. DMG содержит версии для **Apple Silicon и Intel**. Текущий CI выполняет нативные проверки на Apple Silicon; выполнение текущей версии на Intel отдельно не подтверждено. Корпоративные ограничения могут помешать настройке сна. Защита экрана доступна отдельно, даже если настройка сна не выполнена.

При желании проверьте целостность загрузки: скачайте рядом с DMG файл **SHA256SUMS.txt** из того же релиза, откройте Терминал в этой папке и выполните:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Ожидаемый результат — `NoSleep-universal.dmg: OK`. При несовпадении не устанавливайте файл; скачайте его заново из того же релиза. Контрольная сумма проверяет целостность, но не заменяет подпись Apple.

## Использование

- Переключатели сна, экрана и автоблокировки работают независимо. Общая кнопка **«Включить всё / Выключить всё»** управляет всеми тремя функциями; отмена запроса пароля оставляет общую операцию незапущенной.
- Статус показывает подтверждённую защиту, применение команды, проверку прав или ошибку. При ошибке прочитайте пояснение и повторите действие; отправка команды сама по себе не означает, что защита включена.
- Закрытие окна оставляет приложение в фоне. **«Выйти»**, выход из Dock или ⌘Q снимают защиту и завершают приложение. Выбранные переключатели питания сохраняются между запусками.
- При выключении или перезапуске Mac приложение спрашивает подтверждение. **«Отмена»**, Enter или Escape сохраняют приложение и защиту, отменяя эту попытку выключения/перезапуска. **«Продолжить»** снимает защиту и разрешает завершение. При ошибке снятия защиты приложение остаётся открытым и показывает ошибку. Выход из учётной записи проходит без этого диалога. Если NoSleep управляет автоблокировкой, любой обычный выход сначала предлагает восстановить исходную задержку с паролем; отмена или ошибка сохраняет приложение работающим.

Первоначальная настройка создаёт правило `/private/etc/sudoers.d/nosleep_UID` только для текущей учётной записи и двух команд `pmset -a disablesleep 1` / `pmset -a disablesleep 0`. Подготовленный файл проверяется `visudo`; существующее правило не перезаписывается. Пароль администратора запрашивает macOS, приложение его не читает и не сохраняет.

## Автоблокировка

**«Не блокировать автоматически»** изменяет системную задержку требования пароля после погасшего экрана. Пароль текущего пользователя Mac вводится внутри NoSleep при изменении; он не сохраняется в файлах, Связке ключей или отчётах. Повторное изменение требует нового пароля. Если целевая настройка уже действует, лишнего запроса нет. Ручная блокировка остаётся доступна.

При выключении галочки и обычном выходе NoSleep восстанавливает сохранённую исходную задержку. После аварийного закрытия системная настройка может остаться изменённой; следующий запуск предлагает восстановление. Сон компьютера, гашение дисплея и блокировка сеанса — разные функции. Блокировка может остановить управление интерфейсом нейронкой; непрерывная работа Computer с уже погасшим экраном отдельно не подтверждена.

## Обновление и удаление

Для обновления сначала выберите **«Выйти»** в работающем NoSleep, затем установите приложение из нового DMG с заменой в «Программах» и запустите его. Во время замены защита NoSleep снята. Сохранённый выбор переключателей остаётся; после запуска проверьте статус защиты. Уже настроенные права не требуют повторной настройки, если правило осталось действительным.

Для удаления сначала выберите **«Выйти»**, затем удалите приложение из «Программ». Если созданное NoSleep правило больше не нужно, администратор может удалить только `/private/etc/sudoers.d/nosleep_UID` для вашей учётной записи. Локальное состояние и журналы находятся в `~/Library/Application Support/NoSleep/`; их можно удалить после выхода из приложения.

## Диагностика

Кнопка **«Отчёт…»** сохраняет ZIP вручную. Типизированные локальные журналы ограничены **200 МБ и семью днями**; секреты, сетевые настройки и системные журналы не экспортируются. [Состав и ограничения диагностики](docs/diagnostics.md).

## Сборка и проверки для разработчиков

Нужны macOS 14+ и Apple Command Line Tools. Установленному приложению Python и инструменты разработки не требуются.

```sh
./scripts/build.sh
open build/NoSleep.app
```

Для отдельной сборки используйте `NOSLEEP_BUILD_APP=build/candidate/NoSleep.app ./scripts/build.sh`. Обычная сборка подписывается ad-hoc; необязательная локальная подпись разработчика настраивается через [scripts/sign-local-development.py](scripts/sign-local-development.py) и `NOSLEEP_SIGNING_CONFIG`. Это не Developer ID и не нотарификация Apple.

```sh
./scripts/test.sh --core
./scripts/test.sh --ci
./scripts/test.sh --local
```

Runner собирает изолированную копию и проверяет модель питания, диагностику и нативный UI. [Полные проверки и ручная приёмка](docs/testing.md), [правила качества CI](docs/quality-gates.md), [версии и релизы](docs/releases.md), [изменения](CHANGELOG.md). Реальное питание, первая административная настройка, выключение/перезапуск, закрытие крышки и Gatekeeper на другом Mac требуют отдельной ручной проверки; изолированные тесты не подтверждают эти сценарии.

Для сборки универсального DMG:

```sh
python3 -m pip install --target build/packaging-python -r scripts/requirements-dmg.txt
./scripts/package-dmg.sh
python3 tests/dmg_acceptance.py build/NoSleep-universal.dmg
```

Версия 3.6.0 добавляет независимую автоблокировку и восстановление исходной настройки. Информация о сохранённой локальной VM для будущих агентов: [тестовая macOS 27](docs/test-vm.md). Диск VM не входит в репозиторий.

## Временная защита — 4.1.0

Рядом с защитой сна и экрана нажмите «Таймер» со значком таймера: готовые варианты или своё время от 1 минуты до 7 дней. Таймеры независимы; по окончании возвращается выбор, который был до запуска. Защита экрана также требует защиты сна.

Пять последних уникальных своих сроков сохраняются отдельно для каждой функции. Крестик удаляет плашку, сохраняя работающий таймер. Обычное закрытие окна оставляет отсчёт в фоне; после выхода отсчёт не возобновляется. При следующем запуске после прерывания восстанавливается исходный выбор. Автоблокировка управляется вручную и запрашивает пароль по прежним правилам.
