# NoSleep

Локальное приложение macOS с двумя независимыми переключателями:

- не позволять Mac засыпать;
- не гасить экран при бездействии.

Окно открывается из Dock или меню значка чашки. Закрытие окна оставляет приложение в фоне. «Выключить всё» снимает обе защиты. «Выйти» снимает защиту и завершает приложение. Выбранные переключатели сохраняются между запусками.

## Сборка и запуск

Нужны macOS 12+ и Apple Command Line Tools. Приложение разработано и проверено на macOS 27.0.1 / Apple Silicon; остальные версии отдельно не проверены.

```sh
./scripts/build.sh
open build/NoSleep.app
```

## Право на изменение сна

Защита экрана использует штатную IOKit power assertion и не требует прав администратора.

Для управления системным запретом сна нужны две команды `pmset -a disablesleep 1` и `pmset -a disablesleep 0`. Установщик `scripts/install-power-helper.command` после согласия пользователя разрешает только текущему аккаунту запускать эти две команды без пароля. Он не даёт право выполнять другие команды администратора. Если нужное правило уже установлено, ничего не меняет.

Приложение проверяет состояние macOS каждую секунду в отдельной очереди и восстанавливает сброшенный запрет, пока переключатель включён. Команды имеют ограничение времени выполнения. После изменения приложение ждёт подтверждения ядра macOS, чтобы не показывать преждевременную ошибку.

Корпоративные настройки могут конфликтовать с режимом работы. Не меняйте профили управления устройством без согласования с администратором. Закрытая крышка выключает встроенный экран физически: переключатель экрана относится к гашению при бездействии. Приложение не обеспечивает доступ к облачным сервисам без интернета.

## Проверки

```sh
./scripts/test.sh
```

Проверяются независимые переключатели, задержка применения настроек, ошибки, восстановление после сброса, сохранение idle assertion при неуспешном восстановлении и работа проверки при занятом потоке интерфейса.

Проверка реального приложения (меняет его переключатели и включает обе защиты в конце):

```sh
open build/NoSleep.app
python3 tests/live_acceptance.py
```

Тест проверяет выключение, отдельную защиту экрана, сохранение выбора после выхода, открытие окна, снятие запрета при выходе и восстановление после внешнего сброса. Требуется заранее согласованное правило команд питания. Физическое закрытие крышки выполняется пользователем отдельно.

Состояние и журнал ошибок находятся в `~/Library/Application Support/NoSleep/` (`state.json`, `ui.json`, `events.log`). Журнал не содержит паролей или токенов.

## Удаление

Сначала нажмите «Выйти», затем удалите приложение. Если правило `nosleep_power` было создано этим установщиком и больше не нужно, администратор может удалить только `/private/etc/sudoers.d/nosleep_power`.
