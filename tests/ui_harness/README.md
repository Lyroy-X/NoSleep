# Изолированный нативный UI E2E

`python3 tests/ui_acceptance.py --no-screenshots` компилирует текущие MenuApp, меню и UI-тесты с fail-closed моделью питания. Он проверяет зависимость экрана от сна, отдельную автоблокировку, команды меню, общую кнопку, настройку первого запуска, старые сохранённые комбинации и отсутствие VPN. Отсутствие разрешения блокирует включение обеих защит питания и прямые команды. Настоящая модель Protection/GuardEngine отдельно проверяется в `tests/control_dependencies_acceptance.py`.

Состояние пишется в уникальный `build/ui-acceptance/<id>/application-support`, настройки изолированы отдельным suite. Запуск обычного жизненного цикла, pmset, административная настройка и экспорт из модели запрещены. Логи, входные SHA и receipt остаются в уникальном каталоге проверки. Сохранённые вспомогательные standalone/VNC инструменты не входят в текущую приёмку.
