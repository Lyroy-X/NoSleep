# NoSleep: луна и огонёк

Утверждено пользователем 14 октября 2026: **вариант 01** на [листе из четырёх вариантов](references/03-moon-variations-approved-01.png). Предыдущая рекомендация касалась 01 и 04; пользователь явно выбрал 01.

## Основная идея
Светлый объёмный полумесяц и тёплый янтарный огонёк на тёмно-синей плитке: спокойный ночной спутник, который остаётся бодрствовать. Название — **NoSleep**.

## Файлы
- [Исходник иконки, полноформатный RGB PNG](../../Resources/NoSleep-icon.png): выделенная через встроенный ImageGen версия утверждённого 01; после исправления системной рамки фон непрозрачный до краёв. Генерация сохраняет направление, но не является буквальным попиксельным вырезанием из листа.
- [Иконка приложения ICNS](../../Resources/NoSleep.icns): размеры 16, 32, 64, 128, 256, 512 и 1024 пикселя.
- [Монохромный SVG](../../Resources/NoSleep-symbol.svg): упрощённая луна с отдельным огоньком для маленьких размеров.
- [Знак меню в AppKit](../../Sources/NoSleepBrand.swift): тот же рисунок, 18 pt, template image для светлого и тёмного меню.
- [Сборка ICNS](../../scripts/build-icons.sh): воспроизводимое преобразование утверждённого PNG штатными sips/iconutil; не требует ImageGen или сетевого доступа.

## Опорная палитра
| Роль | HEX | RGB |
| --- | --- | --- |
| Полночный синий | `#0C1830` | 12, 24, 48 |
| Тёплая слоновая кость | `#FFF1D0` | 255, 241, 208 |
| Янтарный огонёк | `#FFAC21` | 255, 172, 33 |

Это опорные цвета для дальнейшего дизайна; объёмный растровый мастер содержит оттенки, свет и тени. Для меню используется системный монохромный template, а не растровая цветная иконка.

## Правила
- Объёмная версия используется в Dock, Finder и окне «Об этой программе»; монохромная — в меню macOS.
- Сохранять направление раскрытия луны вверх-вправо, пропорции и свободный промежуток между луной и огоньком.
- Не добавлять звёзды, лучи, глаза, буквы или надпись внутрь иконки.
- Не растягивать знак, не перекрашивать объёмный мастер, не заменять луну системным значком «Не беспокоить».
- Для меню и размеров 16–24 px использовать упрощённую геометрию без свечения и фактуры.
- Для macOS 26+ фон исходника должен быть непрозрачным до всех четырёх углов; скругление выполняет система. Повторная плитка с прозрачными полями может привести к светлой системной подложке.
- Подпись в референсах — пробная типографика, не утверждённый отдельный шрифтовой мастер. Лицензия конкретного шрифта не заявляется; приложение сохраняет системную типографику macOS.

## Рецепт генерации
Встроенный ImageGen; источник — четырёхколоночный лист. Выделить только большую иконку первого столбца 01; сохранить толстый мягкий светлый полумесяц, янтарный шарик, тёмно-синюю плитку и раскрытие вверх-вправо. Первый мастер имел прозрачные поля; текущий мастер — полноформатный квадратный RGB PNG без заранее скруглённых углов; убрать номера, надписи, разделители, миниатюры и остальные варианты. Не добавлять новые элементы и не менять концепцию. При исправлении через ImageGen расширен только тёмно-синий фон до краёв; луна и огонёк сохранены.

Оригинальные листы и PNG являются растровыми материалами. SVG и рисунок меню — отдельно построенное упрощение для малого масштаба. Поиск товарных знаков не проводился.

## Исправление светлой рамки в macOS
Первый ICNS был автоматически уменьшен системой и помещён на светлую плитку. У исходного PNG белой рамки не было. Замена прозрачных полей на непрозрачный синий фон устранила вторую плитку при проверке на macOS 27.0.1.

- [Предыдущий исходник](references/06-approved-icon-before-system-mask.png) сохранён.
- [Системная иконка до](previews/system-icon-before.png) и [после](previews/system-icon-after.png) получены через AppKit, без редактирования снимков.
- [Регрессионный тест](../../tests/icon_background_acceptance.swift) проверяет фон источника и наружные области именно системного изображения приложения; на старом bundle тест падает, на исправленном проходит.
- [Apple: App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons/) рекомендует непрозрачный полноформатный фон и квадратные слои, которые маскирует система. Исправление проверено на текущем Mac; внешний вид на macOS 14–25 отдельно не проверен.
