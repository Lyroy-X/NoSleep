# Design

Work from a separate checkout of the exact current GitHub main; leave the existing dirty checkout intact. Remove retired laboratory files and dependent VM operators as one dependency closure. Keep bridge.swift unchanged and remove only tests for the removed operators; execute all five bridge contracts.

README starts with downloading the universal DMG, moving it to Applications, Gatekeeper handling and initial administrative setup. Document verification, update downtime and uninstall state. Remove the reference to an absent Keychain identity test and avoid claims of automated real-power or Intel acceptance.

The regression runner adds focused checks for retired file removal, personal paths and README targets. Application behavior is established by the unchanged source diff and complete isolated native/package checks, not by deleting failed tests of supported behavior. No history rewrite, license decision, GitHub settings change or publication is included.
